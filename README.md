## 📦 Install

Requirements: Node.js `^20.19.0` or `>=22.12.0`, and Yarn 1.x (recommended).

```bash
$ git clone https://github.com/WinmezzZ/react-antd-admin.git
$ cd react-antd-admin

# npm
$ npm install
$ npm run dev

# yarn
$ yarn install
$ yarn dev
```

## 🔨 Build

```bash
# npm
$ npm install
$ npm run build

# yarn
$ yarn install
$ yarn build
```

The production output is generated in `dist`. To deploy under a sub-path, configure Vite's `base` option in `vite.config.ts`.

## 🖥 Browsers support

The project targets modern browsers according to the `browserslist` configuration in `package.json`. Internet Explorer is not supported.
